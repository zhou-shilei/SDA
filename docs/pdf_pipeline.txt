PDF 到 dataset 主流程

完整运行：
  ../envs/sda/bin/python src/run_document_pdf.py /path/to/source.pdf \
    --document-id WO2026086808A1 --run-dir /path/to/new/run --device gpu:0

输出：<run-dir>/results/<document-id>/dataset.json。
同目录包含 template.completed.json、逐表 OCR、证据、覆盖/缺失清单和 report.html。

入口和调用关系：
  studio/server.py           网页上传、任务状态与后台命令
  src/run_document_pdf.py    PDF 流程编排、检查点续跑、运行报告
  src/pdf2fig.py             版面检测与表格裁图
  src/paten_ocr.py           全页 OCR；document_vl.py 提供 VL 后端
  src/graph.py              表格/文档处理的命令行与图入口
  src/pipeline.py           OCR 调度、逐表抽取或文档级抽取
  src/document_extraction.py 文档抽取、响应 schema、证据校验、覆盖修补
  src/agent.py              模型适配与各类语义抽取
  src/schema_pipeline.py    固定模板、证据补全、dataset 导出
  src/template_agent.py     字段状态、来源、实体装载和测量导出
  src/template_sequence_agent.py 序列证据检索与关联

其余 src 模块为上述流程的 OCR、续表、方向、序列目录、正文证据、计时和 token 依赖。
文档级与逐表模式均保留；本次目录清理不改变上传任务选择的抽取模式。
测速、独立审计、对照模型、网页正文补录及单独序列重放脚本已移除。
历史实验数据与输出保存在 baseline/、validation_results/；这些归档不参与正式入口依赖。
