TemplateAgent 和 TST 正文补全

文档模式新增 TemplateAgent.complete() 序列证据工具循环，默认开启：主动检索/读取、
定义覆盖审计、组件关联提议和独立模型核验，详见 docs/template_sequence_agent.txt。
下面的 TST 路线主要用于逐表模式；文档模式仍关闭通用 TST，避免重复全文补全。

页面证据与短序列映射已接入，参数、缓存和独立验证命令见 docs/page_evidence.txt。

输入：同篇专利的单表提取结果、WIPO ST.26 序列表，以及正文段落或 PDF OCR 行。
输出：dataset.json（自然结构和原实验顺序的六字段 records）、template.completed.json
（逐槽状态和来源）、missing_fields.json（仍缺少明确证据的必需字段）、tst_completion.json
（计数、逐实例抽取、核验、拒绝和耗时审计）。template.json 保留补全前的状态。

固定定义：schemas/antibody.schema.json。
从 dataagent 迁入的领域定义快照：schemas/antibody_knowledge.json；来源哈希：source_manifest.json。
Schema 由领域定义维护，不让模型每篇专利重新发明列。TemplateAgent 按原表装载证据：
  entity
    NAME
    VH: sequence, seq_id, CDRH1–3, FRH1–4
    VL: sequence, seq_id, CDRL1–3, FRL1–4
    H_CHAIN / L_CHAIN: sequence, seq_id（完整重轻链，独立于 VH/VL）
    METRIC[]: observation_id, label, metric, value, unit, conditions, experiment_type, target
同一分子的多次 IC50 是动态数组实例 IC50-1、IC50-2；KD、ka、kd 不互换。
每条表格测量保留一条观察；不按名称去重，不把不同单位和条件合并。

槽位的 value/status/required/provenance/candidates 仅在模板中维护。
状态区分 missing、present、conflict、unavailable、not_applicable。
没有明确 CDR/FR 数据时它们是可选空槽，不要求靠生物学常识补齐。
已有完整 VH/VL 时不强制猜切 CDR/FR。完整链不作为可变区，无明确边界不截取。
原表数值、限定符、数值类型和单位保持原样。没有证据的字段保留 null。

WIPO 序列目录只在同专利明确的名称—区域—SEQ ID 映射下使用。
原始序列表字符优先于 OCR 转录，差异值和原来源仍作为候选和问题保存。
仅“某条序列存在于 XML”不能证明它属于哪个分子或是 VH/VL。
序列转换只检查编号、条数、长度，不宣称已做完整 ST.26 DTD/语义验证。

TST 的本地领域适配：
  固定 schema 自上而下生成缺失任务；
  按领域类型、名称、指标、表格/实施例线索检索，保留原文次序；
  动态实验先 Counter 计数，再带总数和序号逐一 Extractor；
  验证逐字引用和值，再由独立模型调用检查实体、实验和字段的归属；
  只填缺失槽；拒绝覆盖已有测量、未证明的别名、跨分子或跨实验拼接。
新发现的实验进入 TST report.candidates，供核对，不静默新增表格测量。
现实现使用领域规则和词法检索，不宣称复现论文的 dense retrieval 或基准成绩。
下载的原始论文及 GitHub 在 papers/tst/ 和 vendor/TST/；详见 docs/tst_sources.txt。

主入口（默认已启用 TemplateAgent/TST）：
  python src/graph.py --image-dir data/WO2025108394A1
  --tst-concurrency 4         模型请求最大并发
  --tst-max-tasks 200         每专利的缺失任务上限，超出部分明确留在缺失清单
  --text-pages-jsonl PATH    可选，同篇专利 OCR JSONL 的可追溯行
  --no-text-sequences        不调用正文模型，仍创建模板、查询序列表并报告缺失
  --legacy-text-sequences    沿用原全文序列扫描与最终六字段 LLM 拼接
有表格时由缺口驱动正文补全。没有表格锚点时仍保留原正文发现入口。
计数/抽取/核验分别记录在主 _timings.json 和 TST 审计中。
缺失字段不等于程序失败；模型请求全部失败会明确标为 failed。
即使文档处理完成，仍可能保留无法确定的字段和新发现候选。

无需重新 OCR，可复用已经提取的表格：
  python src/schema_pipeline.py --document-id WO2025108394A1 \
    --input-dir results/WO2025108394A1 --data-dir data/WO2025108394A1 \
    --output-dir validation_results/template_tst/current/WO2025108394A1 --no-retrieval
去掉 --no-retrieval 即执行 TST 正文补全。
--source-extraction baseline/codex/extraction.json 可改用已有 OCR→Codex 提取结果。
--text-pages-jsonl baseline/codex/input/pages.jsonl 可加入同专利的 PDF OCR 行。
省略的表格上下文和超出预算的缺口会保留在报告中，不能当作不存在。

迁移边界：复用 dataagent 的声明式证据计划、构建体区分和实验实例思想，
保留其维护的领域定义；不复制其 OCR/UI/数据库整套应用。
TST 上游是面向论文数据的实验脚本。本项目独立实现相应阶段，模型接口仍用 codexllm。
