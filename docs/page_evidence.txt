页面证据与序列映射（第一版）

主批处理默认启用。沿用已有 table_continuation.py 的几何候选、OCR 列数校验与
分区域指标读取，支持续页 IC50/EC50 和当前页 Ka/Kd/KD 各自保留。
明确表头、单位和单元格可执行时不调用实验抽取模型，否则将验证过的表头上下文
交给 AssayExtractionAgent；不会把前页数据复制到当前页。

table_ocr.extract_table_evidence(image_path, metadata=None) 返回原始 text、HTML
展开行列及物理单元格地址、原始 VL blocks/普通 OCR 行框、图像哈希和运行配置。
extract_table_text(image_path) 保持原来的字符串接口。HTML 不提供的单元格框不伪造。
批处理单表 JSON 的 table_evidence 保留此对象，schema 输出 evidence/tables/ 再保存副本。

page_evidence.PageEvidenceStore：
  按同文档 manifest 定位 source/processing PDF，校验已有哈希；也接受目录内 source.pdf。
  优先本地提取逐页文字和行坐标，缓存 evidence/index.json；质量不足或没有完整定义时，
  按需本地 OCR 候选页。PDF 哈希、OCR 配置/版本变化时旧缓存失效。
  --text-pages-jsonl 显式指定的同篇 OCR 也可作为证据，保留输入哈希及原行地址。
  search_evidence(names=..., seq_ids=..., keywords=...) 返回候选页；
  read_page_evidence(number) 返回可追溯的原始页面行，不向 LLM 自动发送整页。

sequence_mapping 在通用 TST 之前运行：
  每个缺失序列的有名实体只提交相关的连续定义段，长氨基酸行在模型输入中隐藏。
  模型只提出 entity_id / VH或VL / seq_id / evidence_refs。
  程序确认引用来自一个连续定义，编号、名称、可变链明确对应，拒绝跨实体、
  全链/恒定链误作可变区、突变子构建体归到父分子及冲突编号。
  引用扩展为完整原定义段保存，防止 PDF 将名称/链标签拆成多行导致来源丢失。
  WIPO 目录仅用于经过证据关联的编号；没有目录时仅拼接原始纯序列行。
  已填字段和冲突槽不覆盖。同一实体的映射供全部实验复用。
  成功决策按证据、提示词、模型配置缓存，缓存命中后仍重新核验引用。
  自定义 LLM 需声明 cache_identity 才启用持久化决策缓存。
  通用 TST 的实体上下文只带已有序列状态、长度和编号，避免每个实验重复发送残基和来源。

产物：sequence_mapping.json，evidence/pages/，evidence/mappings/，
evidence/mapping_audit/；最终 dataset.json 和 template.completed.json 保留逐字段来源。
预算耗尽、页面识别失败、没有在所选证据中找到映射会明确保留，不宣称全文不存在。
本地 OCR 的计算耗时与远程 LLM token 分别统计；映射请求使用 sequence_mapping 用量阶段。

参数（主入口 src/graph.py）：
  --page-ocr-max-pages 8             每篇专利新增页面 OCR 上限；0 禁用额外 OCR
  --sequence-mapping-max-calls 8      每篇映射请求上限；每次局部证据最多 12000 字符
  --no-page-evidence                 关闭额外页面读取及映射
  --no-text-sequences                禁止正文模型调用（包括页面映射）
页面 OCR 设备沿用主入口的 ocr-device；独立 schema_pipeline 默认 cpu，可用 --page-ocr-device 指定。

复用单表结果，只运行页面映射，跳过通用 TST：
  python src/schema_pipeline.py --document-id WO2025108394A1 \
    --input-dir results/WO2025108394A1 --data-dir data/WO2025108394A1 \
    --output-dir validation_results/page_mapping/WO2025108394A1 \
    --mapping-only --page-ocr-max-pages 0

此命令复用输入的 assay_records。旧运行中已漏掉的续表测量需要重新运行批处理，
或使用已有续表模块生成带来源的派生单表结果后再运行 schema_pipeline；不会修改原始归档。

限制：页面选择是有预算的词法检索；完全无文字的扫描 PDF 首先尝试有限的页面，
不能保证全文检索完毕。双抗多结构域不强制投影为唯一 VH/VL。
本版不以序列长度/相似性推断链边界，不自动套用默认单位。
