# 默认 Table OCR 替换验证

本次修改将生产入口 `document.pdf2doc.extract_table_evidence_batch` 的默认 VL 路径替换为：

PPVL-1.6 表格结构 → 自动方向校正、定位序列单元格与文字行 → 原始像素裁行 → 官方 PP-OCRv6 medium_rec 逐行识别 → 按阅读顺序拼接并回填原单元格。

原 PPVL 文本保存在 `vl_text`，裁行图片、哈希、坐标、置信分数和失败原因保存在 `sequence_ocr`。不使用正文 OCR 改写成功复识别的表格字符，不以规则替换 O/Q 等残基。裁行保留原图中的字符下沿，再去掉多余空白，避免截断 Q 的尾部。

## 数据与网页行为

- 成功复识别的表格字符优先于正文 OCR；正文差异仅作审阅提示，网页显示红色。
- 单纯表文差异不会清空已经解决的 VH/VL，也不会单独触发 QuestionAgent。
- 无法确定的实体归属、链边界、表格与表格之间的矛盾以及真实缺失继续按原有规则保留问题。
- 失败单元格仍保留图片、原始转录和错误信息；序列提取的来源校验拒绝将该失败转录导出为已解决序列。
- 新运行默认使用本策略。历史结果未批量改写；显式复用旧序列表格 OCR 缓存时要求重新 OCR，防止跳过新阶段。
