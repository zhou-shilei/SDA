of a residue (e.g., an amino acid) with each other possible residue a group of positions in the
sequence using a Potts model trained on replacing residues at those positions. As described
above, the scoring checks each possible residue at each position requested. A person of
ordinary skill in the art can recognize that the script can replace residues at each given
position (as in the script of Appendix A). In some embodiments, a similar script could add
residues into the sequence. Each score is calculated with a sequence_energy function, and is
added to an array of scores. For each position examined, sum of the scores in the array are
summed and normalized with a softmax function. The scores are them logarithmically
summed and returned.
